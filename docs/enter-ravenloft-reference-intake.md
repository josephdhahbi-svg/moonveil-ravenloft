## Priorities
1. Ship and verify existing browser game first, including narrator, sound effects and scene interactions.
2. Create original deterministic tables for atmosphere, rumors, trinkets, and non-mechanical encounter hooks; separate roll results from combat or campaign rewards.
3. Add homebrew as opt-in data only after source verification, DM approval, and explicit **homebrew** tags.
4. Use original or properly licensed maps and sounds. Do not silently merge another group's adventure transcripts, rules or character content.
5. Keep canon/official/homebrew status plus author/source, DR era/location, acquisition requirements, and state changes visible in any future registry.

The user's supplied ZIP archives were inspected for the listed files. This intake is not proof of compatibility or authorization to redistribute any third-party material.
